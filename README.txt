GYM TIMER — пакет веб-приложения

Содержимое:
- index.html: приложение, таймер и история тренировок
- manifest.json: настройки установки на главный экран
- service-worker.js: кэширование для офлайн-запуска после первой загрузки
- icon-192.png и icon-512.png: иконки

Быстрый тест:
1. Откройте index.html в современном браузере.
2. Начните тренировку, отмечайте подходы.
3. Нажмите «Завершить и сохранить тренировку».
4. Откройте «История», чтобы посмотреть статистику за последние 7 дней.

Установка как приложения:
Для установки PWA нужен HTTPS-хостинг (или localhost). Загрузите все файлы в один каталог на статический хостинг, например GitHub Pages или Netlify. Затем откройте ссылку на телефоне:
- Android/Chrome: меню браузера → «Установить приложение» или «Добавить на главный экран».
- iPhone/Safari: «Поделиться» → «На экран Домой».

Важно:
- История хранится локально в браузере на конкретном устройстве. Она не синхронизируется между устройствами и может быть удалена при очистке данных браузера.
- Таймер пересчитывает время по системным часам, но браузер/ОС могут ограничивать выполнение фоновой страницы. Для гарантированного фонового таймера и уведомлений потребуется нативная оболочка.
- Звук выключен; уведомления не используются.
